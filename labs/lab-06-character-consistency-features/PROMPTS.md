# Lab 06 — Prompt and Specification Pack

**Character Reference Sheets and Consistency Features**  
Create Short Video Film using AI (TGS-2020505925) · Version v12.0 · 27 September 2026

Reference-sheet and casting prompts. Save every approved sheet as a named element and reuse it by name — never re-describe the character from scratch.

> **Currency note.** Tools and model names are examples of a technique, not endorsements, and AI video features change month to month. The prompt patterns here are tool-neutral. Before relying on a feature, clip length, resolution or price, check the provider's current documentation and terms, and record the model ID and date of every generation you keep.

---

## 1. Character reference sheet

```text
Character reference sheet of MEI, courier in her mid-20s: yellow hooded raincoat, red scarf, black cross-body bag with a chequered patch. Three full-body views - front, side, back - plus a face close-up and three expressions (determined, surprised, smiling). Plain light-grey background, even studio light, same outfit in every view. 16:9.
```

## 2. Structured casting (when you have no photo)

Specify genre, production budget, era, archetype, identity (gender, age), build, distinguishing details and outfit as separate choices rather than one paragraph. Each choice is a feature you can later check.

## 3. Prop plate

```text
Product-style hero shot of a palm-sized red lacquered box with a round brass clasp and a folded paper tag, three-quarter view, plain background, soft key light.
```
