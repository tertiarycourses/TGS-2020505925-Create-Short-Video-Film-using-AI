Edit prompts for state variants, clean-up and generative expand.

> **Currency note.** Tools and model names are examples of a technique, not endorsements, and AI video features change month to month. The prompt patterns here are tool-neutral. Before relying on a feature, clip length, resolution or price, check the provider's current documentation and terms, and record the model ID and date of every generation you keep.

---

## 1. State-variant edit

```text
Use the attached image as the exact base. Same pier, same camera position, same blue-hour light, same rain, same lamp, same captain. The only change: [state change]. Do not change anything else.
```

## 2. Clean-up (inpaint)

```text
Remove the object inside the mask and continue the timber planks and puddles naturally. Keep everything outside the mask unchanged.
```

## 3. Generative expand to 9:16

```text
Extend the image upward and downward to 9:16. Continue the blue-hour sky above and the wet timber pier below in the same style and light. Do not add people, text or new objects.
```
